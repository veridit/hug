## Goal
hug task tui and hug mem tui report an OSC 7577 resume command, so a terminal that supports it reopens them after a restart

## Purpose
After a reboot iTerm2 restores folders and scrollback but not the programs; jhf retypes every command by hand. OSC 7577 (Program Resume Protocol, published 2026-11-25) is a new standard for a program to tell the terminal how to resume it. jhf is preparing iTerm2 support (brief: ~/Projects/osc7577-iterm2-brief.md) and sent jcode a feature request on 2026-11-27.

## Principle
Report only when OSC7577_TOKEN is set. Never write the token anywhere. Strip it from every child hug starts. Send clear only on a deliberate quit. Follow spec rev 0.5 exactly.

## Details
Spec (read fully, short and precise, still moving: 5 revisions in 8 days): https://superlogical.com/rex/docs/build/program-resume

Report: ESC ] 7577 ; pid=<own pid>:time=<unix s>:argv=<b64>,<b64>,...:cwd=<b64 abs path>:mac=<hex> ESC \
mac = sha256 hex of '<body before :mac=>:<token>' (plain SHA-256, token last, not HMAC). Values are standard base64 of UTF-8, no control characters. argv[0] is a bare name looked up on PATH (hug) or an absolute path. Report argv hug,task,tui (or hug,mem,tui) with cwd = the board's repo root.
When: at start, and again whenever the resume command or cwd changes, and after the editor returns (last-write-wins terminals). Send clear=1 when the user quits (q). Never send clear on SIGHUP, SIGTERM or loss of the terminal: that is exactly when the record is needed.
Children: the spec says a program that reports SHOULD remove OSC7577_TOKEN from every program it starts, so the child does not register itself instead.

A shared helper for child env is the clean fix.

Testing without a supporting terminal: set OSC7577_TOKEN=dummy-token-replace-me yourself and capture the bytes (tmux pipe-pane or script). The spec's Examples section gives exact mac values for that token, e.g. lazygit report pid=74877:time=1795543200:argv=bGF6eWdpdA==:cwd=L2hvbWUvdXNlci9zcmMvcHJvamVjdA== -> mac 35cb909805c380336efd3689a125acc774a9dec8422a1d21492ebec06ca758e1, and clear report pid=74877:time=1795543200:clear=1 -> mac c30603369f98fef581a4098be889175b0c74f0641e49f8b25f4326cb38f97c93.
