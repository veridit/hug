## Goal
Each memory is its own file under memories/<first two id chars>/<id>.md; memories.json is retired.

## Purpose
Jørgen 2026-11-26 picked C on b8mk9s: agents writing different memories never wait for each other, and the id is the file name, so links stay stable.

## Principle
One file per memory, written atomically (temp file + rename). Folders by id, never by date, so a memory never moves when edited. Migrate on a copy first; nothing is lost or reordered.

## Details
Today: one memories.json, 21.5 MB, 22,064 memories (store copy 2026-11-26); every remember rewrites the whole file. Two-char id folders give ~1,300 folders of ~17 files. Retired memories go to a _retired/ folder; days kept = b8mk9s check 6 (Jørgen, open). Git: many small files instead of one; say in the CHANGELOG what changes for a repo that shares memories.
