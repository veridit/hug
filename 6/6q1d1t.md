## Goal
After a release that changes how a task file parses, every hug reads findings made by the new rules, not ones an older running hug cached.

## Purpose
crab 2026-11-22 09:27Z: v0.7.103 lint says 9s0vj3's sections are out of order ('the order is ... Acceptance, Details, Questions'), but a fresh board with the same file finds nothing. 8a0ybb renamed Relevant details to Details without bumping cache.SchemaVersion (still "30" in v0.7.101 and v0.7.103). Old hug tui and hug mcp processes from 11-17..11-19 still run; to them Details is an unknown section ranked after Acceptance, and they cached that finding.

## Principle
Any change to Parse, Lint or the section rules bumps SchemaVersion, held by a test; never ask the user to kill processes or delete caches.

## Details
