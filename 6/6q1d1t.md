## Goal
After a release that changes how a task file parses, every hug reads findings made by the new rules, not ones an older running hug cached.

## Purpose

Acceptance, Details, Questions'), but a fresh board with the same file finds nothing. 8a0ybb renamed Relevant details to Details without bumping cache.SchemaVersion (still "30" in v0.7.101 and v0.7.103).
