## Goal
Each file in a task's FILES list shows when it was attached, so the newest is easy to tell from older ones.

## Purpose
Jørgen 2026-11-20 08:52Z (hjbfzd request 2): FILES lists capture-wording, screen-0939 and others with no date, so he cannot tell the new one from the old; hug already knows when each came.

## Principle
Use the time hug recorded, not the file's mtime: a git checkout or sync rewrites mtimes. Short and relative, like the rest of the page (5 min ago, 2 d ago).

## Relevant details
Source: the commit on hug/tasks that added the file (git log -1 --diff-filter=A on the file), or the attach note's time if attach records one. mtime is wrong after a clone or sync. Detail FILES rows today: 'NAME  SIZE' (huginn/internal/tui files.go). Newest first, or keep the order and show the age; the age goes after the size, dim.
