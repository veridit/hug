## Goal
The installed instruction 'While working: hug task check ID N with evidence, hug task note ID "evidence".' matches what the commands accept: hug task check ID N "evidence" ticks item N and stores the evidence as a note in one step (MCP task_update check gains the same optional text), note and check accept --as NAME like take and wait do, and a wrong argument count names the command's own help and the right form instead of 'fix: hug task help'.

## Purpose
Three agents reflected on the same mismatch at done (at3qep, 49n9kw, x1ra0t) and four session transcripts hit 'expected 2 positional arguments, got 3' with 'fix: hug task help'; six hit 'unknown flag --as; valid: --json, --help' on note (p29rbz: a note signed by habit is lost). Each costs a refused write and a retry, and the evidence the instructions ask for ends up split from its tick.

## Principle
The command teaches what the instruction says, so either the command grows to match or the instruction changes; we prefer the command, because 'check with evidence' is the behaviour we want. One step, no new subcommand. Plain 'check ID N' keeps working. Every refusal's fix: line is a command an agent can run as printed.
