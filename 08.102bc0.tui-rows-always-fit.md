## Goal
Every task row in every TUI view (overview sections, list, board, lint) is exactly one terminal line at any width: the title is cut with … to make room, the owner and branch keep their place at the right, and at narrow widths whole columns drop out in a fixed order instead of the row wrapping.

## Purpose
Jørgen 2026-11-16 on the seid-lang overview (2512 tasks, v0.7.36): 'we need to be able to handle all of the things at the same line without a wrap'. Long titles in IN PROGRESS already run up against the owner column, and x1t1t1 check 4 (a8f5756, not on main yet) adds the branch after the owner (alice · feat/x), growing that column up to 30 on wide terminals.

## Principle
Cut, never wrap. The title is cut first, the owner and branch next (branch before owner), then whole columns go in a fixed order (type, then priority, then status), and id and progress pie stay always. Measure in display width (wide runes, emoji), never bytes. One width function for every row kind, so a new column cannot reintroduce a wrap.

## Relevant details
Truncation helper today: huginn/internal/tui/render.go:62 ansi.Truncate(s, width, "…"). Owner column growth is in a8f5756 (render.go). Rebase on x1t1t1 check 4 once it lands on main. Screenshot widths: about 170 columns.
