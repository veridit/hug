## Goal
Each install/repo chooses whether project memories go on the muninn-notes branch (private repos) or stay local (public repos); default local

## Purpose
Project memories that reach a branch are pushed with the repo. hug and muninn are public repos (MPL-2.0) where real memories must never be committed (memories 6ag5b6, 8edxyd), and personal memories never go into a repo (hbzc5e). docs/DESIGN.md (Jørgen's decisions, 2026-11-11) states it: shared memories only reach a branch if the repo setting allows it, default off for public repos.

## Principle
Default local: nothing is pushed unless the repo opts in. The setting is checked by sync itself, so no path can push around it. Decide where the setting lives (check 1) before building the refusal (check 2). Private and personal memories are out of scope: they never reach a repo branch either way.

## Relevant details
Today hug mem sync pushes project memories to branch muninn-notes (.muninn-notes/memories.jsonl, muninn/internal/project/project.go:39), with a secret scan before writes (project/sync.go). The branch is due to move to hug/memory under epic 9taa9d, so the setting should not depend on the old name. Candidate locations named in check 1: a committed marker in the repo vs a per-machine setting.
