## Goal
Each install/repo chooses whether project memories go on the muninn-notes branch (private repos) or stay local (public repos); default local

## Purpose
Project memories that reach a branch are pushed with the repo. hug and muninn are public repos (MPL-2.0) where real memories must never be committed (memories 6ag5b6, 8edxyd), and personal memories never go into a repo (hbzc5e). docs/DESIGN.md (Jørgen's decisions, 2026-11-11) states it: shared memories only reach a branch if the repo setting allows it, default off for public repos.

## Principle
Default local: nothing is pushed unless the repo opts in, and sync itself refuses (check 2) rather than relying on agents to remember. Decide where the setting lives (check 1) before building the refusal. Personal and private memories are out of scope: they never reach a repo branch either way (DESIGN.md: they stay in a local folder).

## Relevant details
Sync pushes project memories as one memories.jsonl on a branch (muninn-notes on main, project.go:39; hug/memory after commit c16b7fd6, not yet on main), with a secret scan before writes (muninn/internal/project/sync.go). The setting should not depend on either branch name. Candidate locations named in check 1: a committed marker in the repo vs a per-machine setting.
