## Goal
The test decides when the killed push happens, not the clock: the hook blocks on a file the test controls instead of sleep 3; no NetTimeout raise. TestUpgradeFailuresKeepOriginalLayout lost-ack, unknown-after (and unknown-before/advanced) pass under any machine load.

## Purpose
Under load the 1 s NetTimeout fires before the push reaches the hook (ack-marker missing) or kills ls-remote (unknown outcome lacks 'local original layout restoration VERIFIED'): a false failure in the landing queue.

## Principle
Fixture change only: the hook waits on a file the test creates when it wants the push killed, and the test releases it before cleanup. Never raise NetTimeout or add retries. hug's push path stays as is.
