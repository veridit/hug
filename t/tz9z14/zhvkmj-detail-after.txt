DESCRIPTION
Each status (todo, doing, blocked, done, dropped) has one subtle color, used in the status word, its section header (NEXT UP, IN PROGRESS, BLOCKED,
RECENTLY DONE) and the overview count line, so a glance tells the state. The progress column shows a fraction only while work is partial: a done
task shows its check count in the done color (● 5), not 5/5.

PURPOSE
Jørgen 2026-11-17 on the hug overview (v0.7.37): 5/5 on done rows says nothing, since lint already requires every check ticked before done; he wants
the plain count in green. He also wants todo, doing, blocked and done to have their own colors, reflected subtly in each section's header.

PRINCIPLE
Subtle, not loud: tint, not background blocks. Reuse the colors the count line already has (todo, doing, blocked red, done green) so there is one
scheme. Red stays for problems only (blocked counts as one). Works in no-color mode by text alone. Proposed, for Jørgen to confirm in review: done
shows ● N; todo with nothing ticked shows the check count dim (○ 3), no 0/3; a fraction or pie appears only when some but not all checks are ticked;
dropped shows no progress.

RELEVANT DETAILS
Progress pie came with d8yx7y (v0.7.33). Count line colors: huginn/internal/tui render. Section headers are all the same blue today. Coordinate with
102bc0 (rows fit one line) in the same render code.
