## Goal
hug tui lists read as a calm sectioned spreadsheet with the task ID as the row header and Excel-like selection.

## Purpose
Jørgen 2026-11-18: the selected row bar and column band are too intrusive and compete with section headings.

## Principle
Quiet by default: one tint for selection, one moving thing (the cursor). Section headings stay distinct from the selected column heading. Prototype first, Jørgen chooses, then implement with rewritten (not deleted) tests.

## Relevant details
hug tui lists read as a calm sectioned spreadsheet: the task ID is the leftmost row header, cells are normal weight on the plain background. Order B chosen (Jørgen 2026-11-20 08:26Z): ID TITLE STAGE ✓ TYPE PRIORITY OWNER; tags are a prefix of the title; the current cell carries the > cursor, never an underline (underline is the view line's passive active-view mark).

The view line is out of scope here (Jørgen 2026-11-20 08:27Z, request 3: designed better since): its design is r80svs (v0.7.82: bold = a key you can press, colour = the key step, underline = state). Check 3 was built for an older view-line design and is superseded.

Prototype on branch mock/grid (puppy), worktree /Users/jhf/.jcode/scratch/grid-mock, REPORT.md there. Cursor spec shared with qpp30y.
