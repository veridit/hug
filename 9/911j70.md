## Goal
hug tui lists read as a calm sectioned spreadsheet: the task ID is the leftmost row header, selection tints only the row's ID and the column's heading, cells are normal weight on the plain background, and the view line keeps stable two-step key colours with one blinking underline cursor.

## Purpose
Jørgen 2026-11-18: the selected row bar and column band are too intrusive and compete with section headings; the view line recolours as a whole on v.

## Principle
Quiet by default: one tint for selection, one moving thing (the cursor). Section headings stay distinct from the selected column heading. Prototype first, Jørgen chooses, then implement with rewritten (not deleted) tests.

Prototype on branch mock/grid (puppy), worktree /Users/jhf/.jcode/scratch/grid-mock, REPORT.md there. Order A: ID ✓ TYPE PRIORITY STAGE TITLE OWNER. Order B: ID TITLE STAGE ✓ TYPE PRIORITY OWNER. Cursor spec shared with qpp30y: accent #00bfff/#006c9c, underline+bold, blink 530 ms.
